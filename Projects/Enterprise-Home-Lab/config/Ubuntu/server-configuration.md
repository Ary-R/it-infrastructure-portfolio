# Ubuntu Server Configuration

## Role

Ubuntu Server functions as an internal server within the Enterprise Home Lab environment.

---

## Configuration

Implemented:

- Static IP configuration
- Network connectivity through pfSense
- Linux server administration
- Remote management

---

## Security Configuration

Applied:

- System updates
- User permission management
- SSH configuration
- Service review

---

## Purpose

The Ubuntu server provides a realistic enterprise Linux environment for infrastructure management and security testing practice.

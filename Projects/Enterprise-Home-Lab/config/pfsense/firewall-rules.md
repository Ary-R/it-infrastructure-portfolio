# pfSense Firewall Rules

## Objective

Firewall rules are configured to control traffic flow between different network segments.

---

## LAN Rules

Allowed:

- Internal network communication
- DNS requests
- Internet access through NAT

---

## Security Testing Network Rules

Allowed:

- Kali Linux security testing activities
- Network discovery within the lab environment
- Traffic analysis

Restricted:

- Unauthorised access between network segments

---

## Security Approach

The firewall configuration follows the principle of least privilege by allowing only required communication.

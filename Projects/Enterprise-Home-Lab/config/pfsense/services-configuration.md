# pfSense Services Configuration

## Enabled Services

### DHCP Server

Purpose:

- Automatically assigns IP addresses to connected lab systems.

---

### DNS Resolver

Purpose:

- Provides DNS resolution for internal network devices.

---

### NAT

Purpose:

- Allows internal virtual machines to access external resources through the WAN interface.
